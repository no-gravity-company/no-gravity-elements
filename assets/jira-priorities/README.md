# Jira priority icons

Colored circles for the priorities of the No Gravity Jira site (https://nogravity.atlassian.net), instead of the
default bar icons (founder request, 2026-11-13). Jira loads them by URL through jsDelivr, pinned to a commit:
`https://cdn.jsdelivr.net/gh/no-gravity-company/no-gravity-elements@<sha>/assets/jira-priorities/<name>.svg`.

| Priority | Color | File |
|---|---|---|
| Highest | #AE2E24 dark red | highest.svg |
| High | #E2483D red | high.svg |
| Medium | #F5A623 orange | medium.svg |
| Low | #22A06B green | low.svg |
| Lowest | #8590A2 grey | lowest.svg |

PNG copies (16 and 32 px) are here for tools that do not render SVG. Not part of any package.
